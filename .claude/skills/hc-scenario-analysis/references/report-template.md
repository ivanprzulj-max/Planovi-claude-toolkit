# Deliverable Structure and Presentation Standards

Write in the language of the source document (usually Croatian). Chapter titles below are given bilingually; use the document's terminology (CTS, OIE, mjere EnU, etc.). Default deliverable: Word document per the docx skill (read /mnt/skills/public/docx/SKILL.md first) with an Excel model annex; PPTX summary only on request.

## Chapter structure

1. **Sažetak / Executive summary** — the optimal pathway in one page: recommended mix per milestone, system LCOH trajectory, total investment by period, binding constraints, key conditional assumptions (top 3–5 register items), no-regret vs. contingent measures.
2. **Ulazni podaci i pretpostavke / Inputs and assumptions** — data inventory with document citations; summary of the Assumption Register (full register in annex); reconciliation of any inconsistencies found in the source study.
3. **Projekcija potreba / Demand projection** — baseline, EE-measure impact, new connections, net demand and peak per milestone; chart: demand waterfall base year → 2050.
4. **Karakterizacija mjera / Supply option characterization** — one standardized profile per candidate (capacity, output, LCOH, lead time, spatial status, resource cap, risks); LCOH comparison chart (ungranted, with granted shown as secondary marker).
5. **Scenariji / Scenarios** — definition logic, feasibility screening results (explicitly list measures excluded for timing/spatial reasons and why).
6. **Optimizacija i rezultati / Optimization results** — per scenario and milestone: supply mix (MWh and MW tables + stacked charts), dispatch summary (full-load hours per unit), system LCOH, investment timeline (Gantt by measure with lead-time phases), marginal cost of KPI compliance.
7. **Provjera KPI / KPI compliance** — the compliance matrix per scenario (format in kpi-compliance.md), Art. 26 status per period with the option relied upon, binding constraints.
8. **Analiza osjetljivosti i rizici / Sensitivity and risk** — tornado charts on system LCOH, switching values, KPI robustness, qualitative risk register with mitigations.
9. **Preporuke / Recommendations** — phased action plan: decisions needed now (permits, land, contracts, grid applications) with deadlines derived from lead times ("to commission X by 2031, the decision and permitting start no later than Q_/20__"); financing outline; monitoring KPIs.
10. **Prilozi / Annexes** — full Assumption Register; model input/output tables; methodology note (formulas actually used); source citation list.

## Presentation rules

- Every number traces to: (document, page/table) or (A-xx). Spot-check totals against the source document and state the reconciliation.
- Tables: real EUR base-year, units in headers, one decimal for LCOH (EUR/MWh), thousands separators per language convention.
- Charts to always include: demand trajectory; supply mix stacked by milestone; LCOH ranking of measures; system LCOH per scenario; investment timeline; tornado.
- Never present an infeasible scenario as viable; if the client's desired KPI cannot be met on time, the headline is the earliest feasible compliance year and what unlocks it.
- Close the executive summary with the conditionality sentence: results hold under the Assumption Register; items flagged "decision-critical" should be firmed up (studies/quotes/permits) before investment decisions.
